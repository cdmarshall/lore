Pixel-sprite button for Lore surfaces; uppercase Pixelify Sans label, square corners, hard offset shadow that collapses on press.

```jsx
<Button variant="gold" onClick={save}>Download snapshot</Button>
<Button variant="secondary" size="sm">Add note</Button>
```

Variants: `primary` (ink), `secondary` (outline), `gold` (signet metal, key actions), `arcane` (magic/delegate-to-Lore), `ghost`. Sizes `sm|md`.
